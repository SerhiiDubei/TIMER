# ✅ Чеклист запуску проекту

## 📋 Перед запуском

### 1. Встановлення та конфігурація

- [ ] Node.js встановлено (v18+)
- [ ] Виконано `npm install`
- [ ] Всі залежності встановлені без помилок

### 2. Supabase налаштування

- [ ] Створено проект на [supabase.com](https://supabase.com)
- [ ] Виконано `supabase-schema.sql` в SQL Editor
- [ ] Перевірено, що всі 4 таблиці створені:
  - [ ] rooms
  - [ ] players
  - [ ] codes
  - [ ] events
- [ ] Перевірено, що функції створені:
  - [ ] calculate_remaining_time()
  - [ ] check_eliminations()
- [ ] Row Level Security (RLS) увімкнено
- [ ] Replication увімкнено для:
  - [ ] rooms
  - [ ] players
  - [ ] events

### 3. Environment Variables

- [ ] Створено файл `.env.local`
- [ ] Додано `NEXT_PUBLIC_SUPABASE_URL`
- [ ] Додано `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- [ ] Додано `SUPABASE_SERVICE_ROLE_KEY`
- [ ] Додано `NEXT_PUBLIC_APP_URL` (http://localhost:3000)
- [ ] Додано `CRON_SECRET` (будь-який випадковий рядок)

### 4. Перший запуск

- [ ] Виконано `npm run dev`
- [ ] Сервер запущено без помилок
- [ ] Відкрито http://localhost:3000
- [ ] Сторінка завантажилась

## 🧪 Тестування функціоналу

### Крок 1: Створення кімнати (Admin)

- [ ] Натиснуто "Create New Room (Admin)"
- [ ] Введено стартовий час (наприклад, 20 хв)
- [ ] Натиснуто "Create Room"
- [ ] Отримано:
  - [ ] Room Code (6 символів)
  - [ ] Перенаправлено на admin panel
- [ ] **ВАЖЛИВО:** Зберегли admin key з sessionStorage (якщо потрібно)

### Крок 2: Приєднання гравців

- [ ] Відкрито в інкогніто/іншому браузері http://localhost:3000
- [ ] Введено Room Code
- [ ] Введено ім'я гравця
- [ ] Натиснуто "Join Game"
- [ ] Перенаправлено в лобі
- [ ] В адмін панелі побачили нового гравця

**Повторити для 2-3 гравців:**
- [ ] Гравець 2 приєднався
- [ ] Гравець 3 приєднався

### Крок 3: Генерація кодів (Admin)

- [ ] В адмін панелі обрано тип коду (наприклад, "Add Time Self")
- [ ] Встановлено кількість секунд (наприклад, 300 = 5 хв)
- [ ] Встановлено кількість кодів (наприклад, 5)
- [ ] Натиснуто "Generate Codes"
- [ ] Отримано список кодів (формат: ABC-DEF)
- [ ] Натиснуто "Copy All"
- [ ] Коди скопійовано

**Згенерувати різні типи:**
- [ ] 5x Add Time (+5 хв)
- [ ] 3x Subtract Time (-2 хв)
- [ ] 2x Team Add (+3 хв всім)

### Крок 4: Старт гри (Admin)

- [ ] Всі гравці в лобі
- [ ] В адмін панелі натиснуто "Start Game"
- [ ] Статус змінився на "RUNNING"
- [ ] У всіх гравців з'явився таймер
- [ ] Таймер працює (зменшується)
- [ ] Час синхронний у всіх (різниця < 2 сек)

### Крок 5: Використання кодів

**Як гравець 1:**
- [ ] Ввели код типу "Add Time"
- [ ] Натиснуто "Redeem"
- [ ] Побачили "Code redeemed successfully"
- [ ] Час збільшився на екрані
- [ ] В Recent Activity з'явився запис

**Спробувати той самий код ще раз:**
- [ ] Отримано помилку "Invalid code"
- [ ] Код не спрацював (одноразовий!)

**Як гравець 2:**
- [ ] Ввели код типу "Subtract Time"
- [ ] Час зменшився
- [ ] Побачили зміну

**Як гравець 3:**
- [ ] Ввели код типу "Team Add"
- [ ] Час збільшився у ВСІХ гравців
- [ ] Перевірили в адмін панелі

### Крок 6: Rate Limiting

- [ ] Швидко ввели 6 неправильних кодів підряд
- [ ] Отримано "Too many attempts. Please wait."
- [ ] Зачекали 10 секунд
- [ ] Спробували знову - працює

### Крок 7: Перевірка вибуття

**Варіант А: Дочекатись природно (довго)**
- [ ] Зачекали поки у когось час дійде до 0
- [ ] Гравець автоматично eliminated
- [ ] З'явилось "You are eliminated!"
- [ ] Не може вводити коди

**Варіант B: Штучно (для тесту)**
```sql
-- У Supabase SQL Editor
UPDATE players 
SET eliminated_at = NOW() 
WHERE name = 'TestPlayer';
```
- [ ] В UI з'явилось eliminated
- [ ] В списку гравців статус "Out"

### Крок 8: Cron Job (опціонально)

**Запустити локальний скрипт:**
- [ ] Відкрито новий термінал
- [ ] Виконано `node scripts/check-eliminations-loop.js`
- [ ] Скрипт працює (виводить логи кожні 10 сек)
- [ ] Перевіряє кімнати

**АБО налаштувати Vercel Cron після деплою**

### Крок 9: Realtime оновлення

- [ ] Новий гравець приєднався → одразу з'явився в списку
- [ ] Гра стартувала → таймер запустився у всіх одночасно
- [ ] Код використано → event з'явився у всіх
- [ ] Гравець eliminated → статус оновився

## 🐛 Якщо щось не працює

### Помилка: "Failed to fetch"
- [ ] Перевірити `.env.local`
- [ ] Перевірити Supabase URL та keys
- [ ] Перевірити інтернет з'єднання

### Помилка: "Room not found"
- [ ] Перевірити чи виконали SQL схему
- [ ] Перевірити Room Code (правильний регістр)
- [ ] Перевірити RLS policies

### Помилка: "Invalid admin key"
- [ ] Admin key тільки в sessionStorage
- [ ] Не закривайте вкладку адміна
- [ ] Або створіть нову кімнату

### Realtime не працює
- [ ] Перевірити Replication в Supabase
- [ ] Перевірити RLS policies
- [ ] Перевірити browser console на помилки

### Коди не спрацьовують
- [ ] Перевірити чи код правильний (upper case)
- [ ] Перевірити чи не використаний
- [ ] Перевірити логи в API route
