КРОК 3: Виконайте SQL схему в Supabase
----------------------------------------
1. Відкрийте https://supabase.com/dashboard
2. Ваш проект → SQL Editor
3. Скопіюйте ВЕСЬ вміст файлу: supabase-schema.sql
4. Вставте в SQL Editor
5. Натисніть RUN
6. Перевірте що створилось 4 таблиці

КРОК 4: Увімкніть Realtime
----------------------------------------
1. Database → Replication
2. Увімкніть для: rooms, players, events
